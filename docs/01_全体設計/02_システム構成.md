### 補助ライブラリ

直接使うことは少ないが、上のライブラリを動かすために入れているもの。消すと動かなくなるので注意する。

| ライブラリ | 用途 | 使っているもの |
| ---------- | ---- | -------------- |
| `@base-ui/react` | shadcn/ui の部品の土台（動きとアクセシビリティ） | shadcn/ui |
| `class-variance-authority` | 部品のバリエーション（`variant`、`size` など）の定義 | shadcn/ui |
| `clsx` / `tailwind-merge` | クラス名の結合と、Tailwind のクラスの重複の解消 | `src/lib/utils.ts` の `cn()` |
| `tw-animate-css` | 開閉などのアニメーション | shadcn/ui |
| `@hookform/resolvers` | Zod のスキーマを React Hook Form で使う | React Hook Form |
| `@fortawesome/fontawesome-svg-core` / `@fortawesome/react-fontawesome` | Font Awesome を React で表示する | Font Awesome |
| `@tanstack/react-query-devtools` | 開発中にキャッシュの中身を確認する画面 | TanStack Query（本番ビルドには含まれない） |
| `babel-plugin-react-compiler` | React Compiler 本体 | Next.js（`reactCompiler: true`） |
| `shadcn` | 部品を追加する CLI | `pnpm shadcn:add`（`scripts/shadcn-add.mjs`）から呼ぶ |
| `@vitest/coverage-v8` | テストのカバレッジの計測 | Vitest（`pnpm test:coverage`） |
| `server-only` | Client Component から読み込むとビルドエラーにする（`import "server-only"`） | `src/server/` のファイル（[06 アーキテクチャ](./06_アーキテクチャ.md) の「依存の向き」） |

## 4. 環境変数

<!-- 値そのものは書かない。どこで管理するか（.env.local、ホスティングの管理画面など）を書く -->

| 変数名 | 用途 | 公開 | 管理場所 |
| ------ | ---- | ---- | -------- |
| `DATABASE_URL` | （例）DB 接続先 | サーバーのみ | |
| `NEXT_PUBLIC_XXX` | | ブラウザにも公開 | |

- `NEXT_PUBLIC_` で始まる変数はブラウザに渡るので、秘密情報を入れない
- ローカルでは `.env.example` をコピーして `.env.local` を作り、実際の値を書く（`.env.local` は Git で管理しない）
- 変数を追加・削除したら、この表と `.env.example` の両方を更新する
- CI で必要な変数は、GitHub の Secrets に登録して `.github/workflows/ci.yml` で渡す

## 5. レンダリング・キャッシュの方針

| 項目 | 方針 |
| ---- | ---- |
| Cache Components（`cacheComponents`） | 使う（[ADR-012](../04_設計判断/ADR-012_キャッシュの方式.md)） |
| 既定のレンダリング | ビルド時に静的な枠を作り、動的な部分はアクセスのたびに流し込む（Partial Prerendering）。データの取得は、何も指定しなければ動的 |
| キャッシュ | 取得の関数（`src/server/entry/queries/`）に `'use cache'`・`cacheLife`・`cacheTag` で指定する（[04 データ取得・更新](../02_共通設計/04_データ取得・更新.md) の「2」） |
| リクエスト前の処理（`src/proxy.ts`） | 使う / 使わない。使う場合は用途（認証チェック、リダイレクトなど） |
