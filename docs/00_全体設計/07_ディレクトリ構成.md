# 07 ディレクトリ構成

## 1. 全体

<!-- テンプレートの初期状態。フォルダを追加したら更新する -->

```
/
├─ .devcontainer/        開発用コンテナの設定
├─ docs/                 設計書
│   ├─ 00_全体設計/
│   ├─ 01_共通設計/
│   └─ 02_画面設計/
├─ public/               静的ファイル（画像など）
├─ src/
│   └─ app/              App Router（ルーティング）
│       ├─ layout.tsx
│       ├─ page.tsx
│       └─ globals.css
├─ next.config.ts
└─ package.json
```

## 2. `src/` の構成方針

<!-- 例として一般的な分け方を記入してある。採用するものに合わせて直す -->

| ディレクトリ | 置くもの | 例 |
| ------------ | -------- | -- |
| `src/app/` | ルーティング用のファイル（`page` / `layout` / `loading` / `error` / `route` など）と、その画面だけで使う部品 | |
| `src/app/(group)/` | URL に影響しないグループ分け（route group）。レイアウトを分けたいときに使う | `(auth)`, `(admin)` |
| `src/app/**/_components/` | その画面だけで使うコンポーネント。先頭が `_` のフォルダはルーティングの対象外 | |
| `src/components/` | 複数の画面で使うコンポーネント | `Button`, `Header` |
| `src/lib/` | ユーティリティ、外部サービスのクライアント | |
| `src/actions/` | 複数の画面で使う Server Action | |
| `src/proxy.ts` | リクエスト前の処理（旧 middleware） | |

## 3. ファイル配置のルール

| 項目 | ルール |
| ---- | ------ |
| import のエイリアス | `@/*` → `src/*`（`tsconfig.json`） |
| ファイル名 | コンポーネントは PascalCase / その他は kebab-case など |
| 同じ場所に置くもの（コロケーション） | 画面専用の部品やテストは、その画面のフォルダに置く / 置かない |
