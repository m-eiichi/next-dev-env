## 5. レンダリング・キャッシュの方針

| 項目 | 方針 |
| ---- | ---- |
| Cache Components（`cacheComponents`） | 使う / 使わない |
| 既定のレンダリング | 静的 / 動的 |
| リクエスト前の処理（`src/proxy.ts`） | 使う / 使わない。使う場合は用途（認証チェック、リダイレクトなど） |
