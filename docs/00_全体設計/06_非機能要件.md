# 06 非機能要件

## 1. 性能

| 項目 | 目標 | 測り方 |
| ---- | ---- | ------ |
| LCP | 2.5 秒以内 | Lighthouse / Vercel Speed Insights など |
| INP | 200 ms 以内 | |
| CLS | 0.1 以下 | |
| 想定アクセス数 | | |

## 2. セキュリティ

| 項目 | 方針 |
| ---- | ---- |
| 認証方式 | 詳細は 01_共通設計 に書く |
| 認可のチェック | page と Server Action の両方でチェックする（`proxy.ts` だけに頼らない） |
| 入力の検証 | サーバー側で必ず行う |
| 秘密情報 | 環境変数で管理し、リポジトリに含めない |
| セキュリティヘッダー | CSP など。`next.config.ts` の `headers` で設定するかどうか |
| 依存パッケージの脆弱性 | `pnpm audit` / Dependabot など |

## 3. SEO

| 項目 | 方針 |
| ---- | ---- |
| メタデータ | 各画面の詳細設計で `metadata` / `generateMetadata` を決める |
| `sitemap.xml` / `robots.txt` | `src/app/sitemap.ts` / `src/app/robots.ts` で作る / 作らない |
| OGP 画像 | |
| インデックスさせない画面 | 管理画面など |

## 4. アクセシビリティ

| 項目 | 方針 |
| ---- | ---- |
| 準拠する基準 | WCAG 2.2 AA など |
| 確認方法 | eslint の jsx-a11y ルール、axe など |
| 言語設定 | `<html lang="...">`（テンプレートの初期値は `en`） |

## 5. 対応環境

| 項目 | 対象 |
| ---- | ---- |
| ブラウザ | Chrome / Edge / Safari / Firefox の最新版 |
| 端末 | PC / スマートフォン / タブレット |
| 画面幅 | 最小 320px など |
| 対応言語 | 日本語のみ / 多言語対応 |
