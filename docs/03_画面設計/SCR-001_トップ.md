## 2. 画面レイアウト

```
+--------------------------------------+
| Header（共通）                         |
+--------------------------------------+
| [A] 見出しと説明文、サンプル一覧へのリンク   |
| [B] 技術スタック（カード。押すと公式サイト） |
| [C] アーキテクチャ（層のカード。押すと SCR-020） |
```

### 2.1 レスポンシブ

| ブレークポイント | レイアウトの違い |
| ---------------- | ---------------- |
| モバイル (< `sm`) | [B] は 1 列。[C] は層名・パス・説明を縦に並べる |
| `sm` 以上 | [B] は 2 列。[C] は横 1 行に並べる |
| `lg` 以上 | [B] は 3 列 |

## 6. 操作・イベント

| No | きっかけ | 処理内容 | 成功したとき | 失敗したとき |

### 6.1 遷移先

| 遷移先 | きっかけ | 方法 |
| ------ | -------- | ---- |
| SCR-010 サンプル一覧 | [A] の [サンプル一覧を見る] を押す | `<Link href="/example">` |
| SCR-020 層の説明 | [C] の層のカードを押す | `<Link href="/architecture/{layer}">`（カード全体をリンクにする） |
| 各技術の公式サイト（外部） | [B] の技術のカードを押す | `<a href target="_blank" rel="noopener noreferrer">`（カード全体をリンクにする）。外部のサイトなので `next/link` は使わない |

- ヘッダーのサイト名は `/` へのリンク
