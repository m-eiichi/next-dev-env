# 03_画面設計

ページ（画面）ごとの詳細設計を置くフォルダ。

画面一覧と画面遷移図は [01_全体設計/01_サイトマップ・画面一覧](../01_全体設計/01_サイトマップ・画面一覧.md) にまとめてある（そちらが正本）。

## 使い方

1. [\_テンプレート.md](./_テンプレート.md) をコピーし、`SCR-XXX_画面名.md` という名前で保存する
   - 例: `SCR-001_トップ.md`, `SCR-010_商品一覧.md`
   - 番号は機能のまとまりごとに 10 ずつ空けると、後から画面を追加しやすい
2. [画面一覧](../01_全体設計/01_サイトマップ・画面一覧.md#2-画面一覧) に 1 行追加し、このファイルへのリンクを張る
3. 画面遷移が変わったら、同じファイルの画面遷移図を更新する
4. 全画面に共通するもの（ヘッダー、認証、エラー方針など）は `02_共通設計` に書き、各画面からはリンクだけ張る
