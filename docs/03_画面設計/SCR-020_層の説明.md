## 1. 概要

### 1.1 目的

トップ（SCR-001）の「アーキテクチャ」に並べた各層について、要点（役割、やること・やらないこと、import できないもの、サンプルのファイル）と、実際のサンプルから抜き出したコード例を 1 画面で見られるようにする。それ以上の詳しい説明は [06 アーキテクチャ](../01_全体設計/06_アーキテクチャ.md) に任せ、画面からは資料の該当する節を案内する。

### 1.2 ルーティング

| 項目 | 内容 |
| ---- | ---- |
| URL パス | `/architecture/[layer]` |
| 実装ファイル | `src/app/architecture/[layer]/page.tsx` |
| レイアウト | `src/app/layout.tsx` |
| 動的パラメータ (`params`) | `layer`: string。`presentation` / `entry` / `application` / `domain` / `infrastructure` のどれか |
| クエリ (`searchParams`) | なし |

- 5 つの層は `generateStaticParams` でビルド時に静的に作る
- それ以外の `layer` は `notFound()` で 404 にする（`dynamicParams` は `cacheComponents` を有効にすると使えなくなるので使わない）

### 1.3 アクセス権限

| 項目 | 内容 |
| ---- | ---- |
| 閲覧できるユーザー | 全員 |
| 権限がない場合 | なし |
| チェックする場所 | なし |

### 1.4 メタデータ

| 項目 | 内容 |
| ---- | ---- |
| title | 層の名前（例: `ドメイン層 \| Next.js 開発テンプレート`） |
| description | 層の役割 |
| 生成方法 | `generateMetadata` で `layer` から作る |
| OGP / robots | なし |
