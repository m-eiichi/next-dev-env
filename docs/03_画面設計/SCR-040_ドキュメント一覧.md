## 1. 概要

### 1.1 目的

**アプリの機能ではなく、実装の見本**。題材は「ドキュメントのレイアウト」。お絵描きツールのようにドキュメントを作るエディタ（[SCR-041](./SCR-041_ドキュメントエディタ.md)）の入口として、保存したドキュメントの一覧と、新しいドキュメントの作成を置く（役割分担は [03_画面設計/README](./README.md) の「実装の見本」）。

- 登録に成功したら、一覧ではなく作ったもののエディタへ移動する（Server Action の中の `redirect()`）

### 1.2 ルーティング

| 項目 | 内容 |
| ---- | ---- |
| URL パス | `/reports` |
| 実装ファイル | `src/app/reports/page.tsx` |
| レイアウト | `src/app/layout.tsx` |
| 動的パラメータ (`params`) | なし |
| クエリ (`searchParams`) | なし |

### 1.3 アクセス権限

| 項目 | 内容 |

## 2. 画面レイアウト

```
+--------------------------------------+
| Header（共通）                         |
+--------------------------------------+
| [A] 見出しと説明文                      |
| [B] 作成フォーム（名前 ＋ [作成して描く]） |
| [C] 保存したドキュメントの一覧                   |
|     名前（エディタへのリンク）             |
|     部品の数・更新した日時                |
| [D] トップへ戻るリンク                   |
+--------------------------------------+
| Footer（共通）                         |
+--------------------------------------+
```

### 2.1 レスポンシブ

| ブレークポイント | レイアウトの違い |
| ---------------- | ---------------- |
| すべて | 1 列。[C] の各行は、幅が足りなければ名前と部品の数・日時を折り返す |

## 6. 操作・イベント

| No | きっかけ | 処理内容 | 成功したとき | 失敗したとき |

| 遷移先 | きっかけ | 方法 |
| ------ | -------- | ---- |

| SCR-001 トップ | [トップへ戻る] を押す | `<Link href="/">` |
