### F-001 （例）投稿の作成

| 項目 | 内容 |
| ---- | ---- |
| ユーザーストーリー | （ログイン済みユーザー）として、（記事を書いて公開）したい。なぜなら（読者に情報を届けたい）から |
| 前提条件 | ログインしている |
| 入力 | タイトル（必須、100 文字以内）、本文 |
| 処理 | 下書きとして保存する。公開ボタンで公開する |
| 出力・結果 | 投稿の詳細画面に移動する |
| 権限 | 作成者本人だけが編集・削除できる |

#### 業務ルール

<!-- 「〜のときは〜できない」のような決まりごと。ドメイン層（06_アーキテクチャ）の実装の元になる -->

- （例）公開済みの投稿は、もう一度公開できない
- （例）タイトルは空にできない

#### 受け入れ条件

<!-- 「これができていれば完成」と判断する条件。テストの元にもなる -->

- [ ] （例）タイトルを入力せずに保存すると、エラーメッセージが表示される
- [ ] （例）保存すると、一覧の先頭に表示される
- [ ] （例）他人の投稿の編集画面は開けない
