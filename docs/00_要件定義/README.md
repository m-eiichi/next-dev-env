# 00_要件定義

**何を・誰のために・なぜ作るか**を書くフォルダ。依頼者や企画担当と合意する内容を置く。
どう作るか（技術、構成、実装のルール）は [01_全体設計](../01_全体設計/) 以降に書く。

| ファイル | 内容 |
| -------- | ---- |
| [01 概要](./01_概要.md) | 目的・背景、対象ユーザー、スコープ、主な機能、用語集。最初に読むページ |
| [02 機能要件](./02_機能要件.md) | 機能ごとの詳細（ユーザーストーリー、業務ルール、受け入れ条件） |
| [03 非機能要件](./03_非機能要件.md) | 性能、セキュリティ、SEO、アクセシビリティ、対応環境、運用 |
| [04 業務フロー](./04_業務フロー.md) | 複数の人やシステムが関わる仕事の流れ |

使わないものは消して構わない。消したら、この表からも消す。
