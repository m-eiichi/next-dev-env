## 2. フローごとの詳細

### 2.1 （例）投稿の公開

```mermaid
sequenceDiagram
  actor Author as 投稿者
  participant App as システム
  actor Admin as 管理者

  Author->>App: 下書きを保存する
  Author->>App: 公開を申請する
  App->>Admin: 申請を通知する
  Admin->>App: 内容を確認して承認する
  App->>Author: 公開されたことを通知する
```

| 項目 | 内容 |
| ---- | ---- |
| きっかけ | 投稿者が公開を申請する |
| 完了の条件 | 投稿が公開され、投稿者に通知が届く |
| 例外 | 差し戻されたときは、投稿者が修正して再申請する |
