デザインファイル:

## 1. カラー

Tailwind CSS v4 のため、色は `src/app/globals.css` の CSS 変数と `@theme` で定義する（`tailwind.config.js` は使わない）。

| トークン | 用途 | ライト | ダーク | Tailwind クラス |
| -------- | ---- | ------ | ------ | --------------- |
| `--background` | 背景 | `#ffffff` | `#0a0a0a` | `bg-background` |
| `--foreground` | 本文 | `#171717` | `#ededed` | `text-foreground` |
| `--muted` | 控えめな背景（コードブロックなど） | `#f4f4f5` | `#18181b` | `bg-muted` |
| `--muted-foreground` | 補足の文字 | `#52525b` | `#a1a1aa` | `text-muted-foreground` |
| `--border` | 枠線、区切り線 | `#e4e4e7` | `#27272a` | `border-border` |
| `--primary` | 強調、主ボタン、リンク | `#2563eb` | `#60a5fa` | `text-primary` / `bg-primary` |
| `--primary-foreground` | `--primary` の上に置く文字 | `#ffffff` | `#0a0a0a` | `text-primary-foreground` |
| `--danger` | （例）エラー、削除 | | | `text-danger` |

- `--background` / `--foreground` はテンプレートの初期値
- `pnpm shadcn init` を実行すると shadcn/ui の変数が `globals.css` に追加される。そのときは同じ名前の変数（`--muted`、`--border`、`--primary` など）を shadcn/ui 側にそろえ、この表も直す
- 色を追加するときは、`:root` に変数を定義し、`@theme inline` に `--color-xxx: var(--xxx);` を追加する
- 画面ごとに色コードを直接書かない（`bg-[#123456]` などは使わない）

## 3. タイポグラフィ

| 用途 | サイズ | 太さ | Tailwind クラス |
| ---- | ------ | ---- | --------------- |
| ページ見出し (h1) | 30px（`sm` 以上は 36px） | 600 | `text-3xl font-semibold sm:text-4xl` |
| セクション見出し (h2) | 20px | 600 | `text-xl font-semibold` |
| 本文 | | | `text-base` |
| 補足 | | | `text-sm` |

- フォント: `--font-sans` / `--font-mono`（`src/app/layout.tsx` で読み込む）
- Geist にそろえた（`body` の `font-family: Arial, ...` は削除し、`<body>` に `font-sans` を付けている）。Geist は日本語を含まないので、`--font-sans` の後ろにシステムの日本語フォントを指定している

## 4. 余白・サイズ

| 項目 | ルール |
| ---- | ------ |
| 余白の単位 | Tailwind の既定値（4px 刻み）を使う |
| コンテンツの最大幅 | `max-w-5xl`。左右の余白は `px-4`（`sm` 以上は `px-6`） |
| ブレークポイント | Tailwind の既定値（`sm` 640px / `md` 768px / `lg` 1024px） |
| 角丸 | カード、コードブロックは `rounded-lg` |
