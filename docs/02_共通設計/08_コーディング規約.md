## 1. 命名

| 対象 | ルール | 例 |
| ---- | ------ | -- |
| コンポーネント | PascalCase（ファイル名は kebab-case。[05 ディレクトリ構成](../01_全体設計/05_ディレクトリ構成.md) の「4. ファイル名のルール」） | `UserCard`（ファイルは `user-card.tsx`） |
| 関数・変数 | camelCase | `getUser` |
| 定数 | UPPER_SNAKE_CASE | `MAX_ITEMS` |
| 型 | PascalCase。`I` などの接頭辞は付けない | `User` |
| Server Action | 動詞で始める | `createPost`, `deleteUser` |
| データ取得関数 | `get` / `list` で始める | `getPost`, `listPosts` |
| 真偽値 | `is` / `has` / `can` で始める | `isLoading` |

## 2. TypeScript

| 項目 | ルール |
| ---- | ------ |
| `strict` | 有効のまま（`tsconfig.json`） |
| `any` | 使わない。どうしても必要なら `unknown` にして絞り込む |
| 型の定義 | `type` / `interface` のどちらかにそろえる |
| page / layout の props | Next.js が生成する `PageProps<'/path'>` / `LayoutProps<'/path'>` を使う |

## 3. React・Next.js

| 項目 | ルール |
| ---- | ------ |
| `'use client'` | 必要な最小の部品にだけ付ける。ページ全体に付けない |
| メモ化 | React Compiler が有効なので、`useMemo` / `useCallback` / `memo` は原則書かない |
| 画像 | `<img>` ではなく `next/image` を使う |
| リンク | 画面内の移動は `<a>` ではなく `next/link` を使う |
| 非推奨 API | `middleware.ts` は使わず `proxy.ts` を使う |

## 4. Lint・フォーマット

| 項目 | 内容 |
| ---- | ---- |
| Lint | `pnpm lint`（ESLint、`eslint-config-next`） |
| フォーマッター | Prettier（Dev Container に拡張機能あり）。設定ファイルを置くかどうか |
| 実行のタイミング | CI（GitHub Actions）で必ず実行する。失敗したらマージできない（[11 CI](./11_CI.md)）。保存時 / コミット前（husky + lint-staged など）にも実行するかは任意 |
| 型チェック | `pnpm typecheck`。CI で必ず実行する |
| ファイル名 | `pnpm lint:ls`（ls-lint）。ルールは [05 ディレクトリ構成](../01_全体設計/05_ディレクトリ構成.md) の「4. ファイル名のルール」。CI で必ず実行する |

## 5. Git

| 項目 | ルール |
| ---- | ------ |
| ブランチ | `main` + 作業ブランチ（`feature/xxx`, `fix/xxx`） |
| コミットメッセージ | Conventional Commits（`feat:`, `fix:`, `docs:` など）/ 日本語で可 |
| マージ | Pull Request を作り、CI が通り、レビューを受けてからマージする |
