# 05 フォーム・バリデーション

## 1. 基本方針

| 項目 | ルール |
| ---- | ------ |
| 送信方法 | `<form action={serverAction}>` を使う |
| バリデーションのライブラリ | Zod / Valibot など |
| スキーマの置き場所 | Client と Server で同じスキーマを使う（例: `src/lib/schemas/`） |
| サーバー側のチェック | **必須**。Client 側のチェックは使いやすさのためのもので、省略されうる前提で扱う |
| Client 側のチェック | する / しない。する場合、いつ表示するか（入力中 / フォーカスが外れたとき / 送信時） |

## 2. 送信中・結果の表示

| 状態 | 表示 | 実装 |
| ---- | ---- | ---- |
| 送信中 | 送信ボタンを無効にし、スピナーを出す | `useActionState` の `pending` / `useFormStatus` |
| 項目のエラー | 項目の下に赤字で表示する | Server Action が返す `fieldErrors` |
| フォーム全体のエラー | フォームの上に表示する | Server Action が返す `message` |
| 成功 | トーストで通知する / 別の画面へ移動する | |
| エラー後の入力値 | 消さずに残す | |

- Server Action の戻り値の形は [04 データ取得・更新](./04_データ取得・更新.md#戻り値の形) にそろえる

## 3. 共通のチェックルール

| 項目 | ルール | エラーメッセージ |
| ---- | ------ | ---------------- |
| 必須 | | `{項目名}を入力してください` |
| 文字数 | | `{項目名}は{n}文字以内で入力してください` |
| メールアドレス | | `メールアドレスの形式が正しくありません` |
| パスワード | 8 文字以上、英数字を含むなど | |
| 前後の空白 | 取り除いてからチェックする / しない | - |

## 4. アクセシビリティ

- 入力欄には `<label>` を付ける
- エラーのある入力欄には `aria-invalid="true"` を付け、`aria-describedby` でエラーメッセージと結び付ける
