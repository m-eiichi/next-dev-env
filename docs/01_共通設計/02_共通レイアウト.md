# 02 共通レイアウト

## 1. layout の階層

<!-- route group ごとにレイアウトを分ける場合の例。実際の構成に合わせて直す -->

```
src/app/layout.tsx              ルート（<html>, <body>, フォント, globals.css）
├─ (public)/layout.tsx          公開ページ用: ヘッダー + フッター
├─ (auth)/layout.tsx            ログイン画面など: ロゴだけの簡素なレイアウト
└─ (app)/layout.tsx             ログイン後: ヘッダー + サイドバー
```

| layout | 使う画面 | 含むもの |
| ------ | -------- | -------- |
| `src/app/layout.tsx` | 全画面 | `<html lang>`、フォント、`globals.css`、共通の `metadata` |
| | | |

- `layout` は画面を移動しても再レンダリングされず、state が残る。画面を移動するたびに初期化したいものは `template.tsx` に置く

## 2. ルートレイアウトの設定

| 項目 | 現在の値（テンプレート） | 決定値 |
| ---- | ------------------------ | ------ |
| `<html lang>` | `en` | `ja` など |
| フォント | Geist / Geist Mono（`next/font/google`） | |
| `metadata.title` | `Create Next App` | テンプレート形式 `{ template: '%s | サイト名', default: 'サイト名' }` など |
| `metadata.description` | `Generated by create next app` | |
| favicon | `src/app/favicon.ico` | |

## 3. ヘッダー

| 項目 | 内容 |
| ---- | ---- |
| 表示する要素 | ロゴ、グローバルナビ、ログイン状態（ユーザー名 / ログインボタン） |
| 固定するか | スクロールしても上部に固定する / しない |
| モバイル | ハンバーガーメニューにするなど |
| コンポーネント | `src/components/Header.tsx`（Server）+ メニュー開閉部分だけ Client |

## 4. フッター

| 項目 | 内容 |
| ---- | ---- |
| 表示する要素 | コピーライト、利用規約・プライバシーポリシーへのリンク |

## 5. ナビゲーション

| 項目 | 方針 |
| ---- | ---- |
| 画面内のリンク | `next/link` の `<Link>` を使う |
| 現在の画面の強調 | `usePathname()` で判定（Client Component） |
| パンくずリスト | 使う / 使わない |
| プログラムでの画面移動 | Server 側は `redirect()`、Client 側は `useRouter().push()` |
