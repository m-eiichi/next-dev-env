# 07 ログ・監視

<!-- 運用の方針（保持期間など）は 00_全体設計/06_非機能要件 に書く。ここは実装のルール -->

## 1. ログの出し方

| 項目 | ルール |
| ---- | ------ |
| 使うもの | `console` / ロガーライブラリ（pino など） |
| 形式 | テキスト / JSON（本番環境は JSON がおすすめ） |
| 出力先 | ホスティングのログ機能 / 外部サービス |

## 2. ログレベル

| レベル | 使う場面 | 例 |
| ------ | -------- | -- |
| error | 想定外のエラー。対応が必要 | DB 接続の失敗 |
| warn | 想定内だが注意が必要 | 外部 API のリトライ |
| info | 重要な操作の記録 | ログイン、データの作成・削除 |
| debug | 開発中の調査用。本番では出さない | |

## 3. 出してはいけない情報

- パスワード、トークン、API キー
- クレジットカード番号などの決済情報
- 必要のない個人情報（メールアドレスや住所は、マスクするか ID に置き換える）

## 4. エラー監視

| 項目 | 方針 |
| ---- | ---- |
| サービス | Sentry など / 使わない |
| サーバー側のエラーの受け取り | `src/instrumentation.ts` の `onRequestError` |
| ブラウザ側のエラーの受け取り | `src/instrumentation-client.ts` |
| 通知先 | Slack / メールなど |
