## 7. データ取得・更新

### 7.1 取得

| No | 取得するデータ | 取得元 | 実行する場所 | キャッシュ | 再検証 |
| -- | -------------- | ------ | ------------ | ---------- | ------ |
| 1 | | DB / 外部 API | Server Component | なし / `'use cache'` + `cacheLife(...)` | `cacheTag` / `revalidateTag` |

- データの取得は Server Component の中で行うのが基本。取得に時間がかかる部分は `<Suspense>` で囲み、ストリーミングで表示する
- リクエスト単位の情報（`cookies()` / `headers()`）を使うデータはキャッシュしない。どうしてもキャッシュする場合は `'use cache: private'` を使う

### 7.2 更新

| No | 処理 | 方式 | 入力 | 出力 | 更新後にすること |
| -- | ---- | ---- | ---- | ---- | ---------------- |
| 1 | | Server Action / Route Handler (`route.ts`) | | | `revalidatePath` / `revalidateTag` / `refresh` |

- 画面から直接呼ぶ更新は Server Action にする。外部から呼ばれる API や Webhook は Route Handler にする
- Server Action は外から直接呼び出せるので、**中で必ず認証と認可をチェックする**

## 8. 状態ごとの表示

| 状態 | 表示内容 | 実装 |
| ---- | -------- | ---- |
| 読み込み中 | スケルトン | `loading.tsx` / `<Suspense fallback>` |
| 0 件 | 「該当するデータがありません」 | page の中で分岐 |
| 見つからない | 404 画面 | `notFound()` → `not-found.tsx` |
| 未認証 / 権限なし | | `unauthorized()` / `forbidden()` / `redirect()` |
| エラー | エラーメッセージと再試行ボタン | `error.tsx`（`'use client'` が必要） |
| 送信中 | ボタンを無効にし、スピナーを出す | `useActionState` / `useFormStatus` |
