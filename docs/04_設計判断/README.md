# 04_設計判断

設計で**何を決めたか・なぜそうしたか・他に何を検討したか**を残すフォルダ（ADR: Architecture Decision Record）。
「どうするか」のルールは 00〜03 の資料に書き、ここにはその**理由**を書く。後から「なぜこうなっているのか」と聞かれたときや、方針を見直すときの根拠にする。

## 書き方

1. [\_テンプレート.md](./_テンプレート.md) をコピーし、`ADR-{3 桁の番号}_{判断の短い名前}.md` という名前で保存する
2. 上の一覧に 1 行追加する
3. 決めたルールは、00〜03 の該当する資料にも書く（ADR からはリンクする）

### 状態

| 状態 | 意味 |
| ---- | ---- |
| 提案 | 検討中。まだ決まっていない |
| 採用 | 決定済み。今のルールになっている |
| 置き換え | 新しい ADR で方針を変えた。本文の先頭に、置き換えた ADR へのリンクを書く |
| 廃止 | 方針自体をやめた |

- 一度「採用」にした ADR の本文は書き換えない。方針を変えるときは新しい ADR を作り、古い方の状態を「置き換え」にする（当時どう考えたかを残すため）
- 誤字の修正やリンクの追加は、書き換えてよい
