# 実装の見本を消す

見本の一覧と役割は `docs/03_画面設計/README.md` の「実装の見本」。消す場所の一覧は、画面を足すときと共通の [../add-feature/references/touch-points.md](../add-feature/references/touch-points.md) にある。この skill は、その一覧を逆にたどる。

## 0. 最初にユーザーに確かめること

消した後は、git から戻すしかない。作業を始める前に、次を確かめる。

- [ ] どの見本を消すか（メモ / TODO / ほかの見本 / すべて）
- [ ] 消す見本が「3. 見本を見本として参照している所」から参照されているとき、差し替え先をどれにするか（残す見本、または本来の画面）。差し替え先がまだないなら、その見本は残すことを勧める
- [ ] 作業ブランチの上か（`main` の上なら、ブランチを切るか確かめる）

特に、**メモ**は層の説明（SCR-020）のコード例として使っている。メモを消すなら、コード例を別の画面のコードに差し替える必要がある。

## 1. 洗い出す

消す見本ごとに、参照している所を `grep` で洗い出し、ユーザーに一覧を見せる。

```bash
# 例: メモ
grep -rln "メモ\|/notes\|note/\|Note" src docs .claude
# 例: TODO
grep -rln "TODO\|/todos\|todo/\|Todo" src docs .claude
```

- ヒットには、消すものと関係ないもの（「メモリ上の」「メモ化」、コメントの `TODO:` など）が混ざる。1 つずつ見て分ける
- `touch-points.md` の 3 つの表と突き合わせ、表にない場所が見つかったら、そちらの表に足す

## 2. 消す・直す

`touch-points.md` の順に進める。

1. 「3. 見本を見本として参照している所」を先に差し替える（消した後だと、何を載せていたかがわからなくなる）
2. 「1. コード」を消す。`container.ts` とトップのボタンも忘れない
3. 「2. 資料」を消す・直す。消した画面へのリンクが残っていないか、`grep` でもう一度確かめる
4. 採用済みの ADR は書き換えない

## 3. 仕上げ

- [ ] 洗い出しの `grep` をもう一度流し、残っているのが関係ないものと ADR だけか確かめる
- [ ] CI と同じチェックを流す（層の説明のテストが、コード例のずれを見つける）

```bash
pnpm lint && pnpm lint:ls && pnpm typecheck && pnpm test:coverage && pnpm build && pnpm knip
```

- [ ] skill `app-check` で、残した画面（トップ、層の説明など）が開けること、消した画面の URL が 404 になること（`/notes=404` のように渡す）を確かめる
- [ ] knip が失敗したら（見本だけが使っていた部品や依存が、使われなくなったときなど）、`docs/02_共通設計/11_CI.md` の「3.3」の「knip が失敗したとき」に従う。消すか `knip.json` で外すかは、ユーザーに確かめる
- [ ] カバレッジが 80% を下回ったら、数字合わせのテストは書かず、ユーザーに伝える（`docs/02_共通設計/10_テスト.md` の「7」）
- [ ] ユーザーへの報告に、消したもの、差し替えたもの、そのままにしたもの（ADR など）を書く
